# Результаты статического исследования, 11 ноября 2026

Исследован пользовательский расшифрованный IPA Standoff 2 1.1.0 / 176383.2, Unity 6000.3.13f1, metadata v39.

## Снятое ограничение анализатора

Поиск code registration в Cpp2IL 2022.1.0-pre-release.21 ограничивал количество модулей числом 400. В этом приложении 483 metadata images / codegen modules; ScriptingAssemblies.json перечисляет 548 сборок. Начальное смещение поиска превышало ограничение, поэтому цикл не выполнялся.

В локальной исследовательской копии инструмента предел увеличен до 4096. Для анализа также создана отдельная копия UnityFramework с декодированными chained rebases формата DYLD_CHAINED_PTR_64_OFFSET. Исходный IPA и код игрового framework не менялись этими преобразованиями. Декодированная копия не предназначена для запуска.

После этого найден code registration 0xAB389A8, metadata registration 0xAF14408, сопоставлены 196 673 определения методов с нативными указателями. Адреса приведены только для воспроизводимости исследования данного файла; модуль не использует их как игровые офсеты.

## Подтверждённые типы

- PlayerBindings наследует UnityEngine.MonoBehaviour; содержит CharacterController, CapsuleCollider и CameraPlaceholder. Это подтверждает статическую предпосылку текущего ESP-адаптера. Runtime-выборка в матче не тестировалась.
- WeaponMetaData является System.ValueType. SkinId и SkinPatternId имеют тип Int32, OwnerId — Byte. Этот тип нельзя найти как Unity Component.
- PlayerAnimationData содержит WeaponSkinId. Это данные анимации, а не подтверждённый механизм обновления визуального контента.
- Внешний вид оружия загружается через отдельные объекты контента и асинхронные методы с lifetime. Среди них найдены возвращающие Material, Texture2D и параметры LOD; сами сервисы являются System.Object, а не MonoBehaviour.
- Регистрация метаданных оружия и активное состояние отображения находятся в отдельных сервисах. Не подтверждены получение их клиентских экземпляров, выбор текущего локального оружия и корректный вызов обновления.

## Статус реализации

После установки диагностической IPA на iPhone 13 подтверждены загрузка модуля и чтение каталога: 1 335 записей скинов, включая 503 StatTrack-варианта, 70 перчаток и 459 наклеек. Пользователь затем сообщил о бане «за читы» при входе в аккаунт. Точный триггер неизвестен; тесты через авторизацию остановлены. Автозагрузка нашего диагностического модуля на XS Max отключена. Полный скинченджер и работа в матче не подтверждены.

На XS Max с активным джейлбрейком прочитаны четыре LifetimeScope и уже созданный DLCService. В его `_actualContentEntries` находятся 3 735 записей; массив имеет ёмкость 4 096. Первые 256 позиций прочитаны через API IL2CPP: из них 152 относятся к скинам, перчаткам и наклейкам. Полная выгрузка требует активной игры на экране.

Подтверждены примеры: M4A1 Impact — 240210, M4A1 Impact StatTrack — 1240210, KnifeMantis Impact — 240211, Gloves Impulse — 3047, Sticker 8Years — 1588. Это определения каталога, а не выданные предметы аккаунта.

Из локального публичного DLC-кэша получен манифест 33 коллекций и 1 735 файлов. Для четырёх примеров загружены публичные ресурсы коллекции 8 Years и построены офлайн-превью из исходных мешей, UV и diffuse-текстур. Игровые файлы, ключи кэша и полученные изображения не включены в публичный репозиторий. Этот рендер не проверяет смену внешнего вида в матче.

На XS Max проверка root останавливает вход в матч. На подключённом iPhone 13 без джейлбрейка подтверждена iOS 26.3; диагностическая IPA подготовлена для отдельного теста. Автоматическая сборка и Simulator smoke test не заменяют этот тест.

Рабочий скинченджер не заявлен и не добавлен. Перед его реализацией требуется проверить цепочку «локальный игрок → активное оружие → метаданные → загрузчик контента → обновление модели» на работающем клиенте. Подмена поля SkinId без этой цепочки не подтверждает визуальную смену и может затронуть сетевое состояние.

Меню и capture suspension проверены отдельным Simulator smoke test. Этот тест не содержит игровых бинарников, не проверяет скинченджер и не подтверждает скрытие реальных эффектов на видеозаписи.
